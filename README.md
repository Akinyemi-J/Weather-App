# Weather-App
## Description
A simple weather application that shows real-time weather data using an API.

## Features
- Search for any city
- Displays temperature, humidity, and weather condition
- Clean UI

## Technologies Used
- HTML
- CSS
- JavaScript
- API (OpenWeather)

## How to Run
1. Clone the repo
2. Open index.html in your browser
